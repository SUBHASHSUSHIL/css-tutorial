HTML Headings (h1 – h6)

HTML provides six heading levels. h1 is the most important (largest) and h6 is the least important (smallest). Use headings to create a logical document outline — never skip levels just for visual size.

Key Points

- Only one <h1> per page (main topic).
- Follow a sequential order: h1 → h2 → h3 ...
- Do NOT use headings just to make text bigger — use CSS for that.
- Headings improve accessibility and SEO.
