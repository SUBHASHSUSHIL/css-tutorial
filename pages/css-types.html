Types of CSS

1. Inline Style

Applied directly on an element using the style attribute. Inline styles have the highest specificity but break the separation of concerns and are hard to maintain at scale.

Example element with inline style:

I am styled with an inline style. 

<p style="background-color: #ffb703; padding: 0.5rem;">...</p>

2. Internal (Embedded) Style

Placed inside a <style> tag in the <head>. Good for single-page demos; not ideal for multi-page sites because styles cannot be shared.

I am styled via an internal (embedded) stylesheet.
<style>
  .demo-internal {
    background-color: #caf0f8;
    border: 4px solid #0077b6;
  }
</style>

3. External Stylesheet

A separate .css file linked via <link>. This is the recommended approach for real projects — one stylesheet can style every page and browsers cache it for performance. 

<!-- Method 1: link tag (recommended) -->
<link rel="stylesheet" href="styles.css">

<!-- Method 2: @import inside a style block (avoid in production) -->
<style>
  @import "styles.css";
</style>

Cascade Order (lowest → highest priority)

1. Browser default styles
2. External stylesheet
3. Internal (embedded) stylesheet
4. Inline style    ← wins

Note: CSS is case-sensitive.
      Every declaration must end with a semicolon ( ; ).
      Multi-word property values should use hyphens: font-size, not fontSize.
