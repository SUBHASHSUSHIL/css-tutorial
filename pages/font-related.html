Font-Related CSS Properties

font-family

Always specify a font stack — multiple fonts separated by commas. The browser uses the first one it finds; the last entry should be a generic family as a fallback.

font-family: serif

font-family: sans-serif

font-family: monospace

font-family: cursive

font-family: fantasy

h2 { font-family: 'Georgia', serif; }

font-style

font-style: normal

font-style: italic

font-style: oblique

p { font-style: italic; }

font-weight

Values: normal (400), bold (700), or 100–900 in steps of 100.

font-weight: 100 (thin)

font-weight: 400 (normal)

font-weight: 700 (bold)

font-weight: 900 (black)

strong { font-weight: 700; }

font-variant

Normal: Hello World

font-variant: small-caps — Hello World

.abbrev { font-variant: small-caps; }

font-size

Prefer rem for scalability; avoid fixed px for body text.

font-size: small

font-size: medium

font-size: large

font-size: 24px

font-size: 1.5rem

font-size: 150%

body  { font-size: 16px; }   /* base */
h1    { font-size: 2rem; }    /* 32px relative to base */
small { font-size: 0.8rem; }

font-stretch

Requires the font to have a condensed/expanded variant installed on the device.

font-stretch: condensed

font-stretch: expanded

p { font-stretch: condensed; }
