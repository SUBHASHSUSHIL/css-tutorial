Margin, Padding & Border

The CSS Box Model

Every HTML element is a rectangular box made of four layers:

┌───────────────────── MARGIN (outside) ──────────────────────┐
│  ┌──────────────────── BORDER ──────────────────────────┐  │
│  │  ┌─────────────── PADDING ───────────────────────┐  │  │
│  │  │                 CONTENT                        │  │  │
│  │  └────────────────────────────────────────────────┘  │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
Content area
(padding → border → margin wrap it)
* {
  box-sizing: border-box; /* width/height includes padding + border */
}

margin

Space outside the border, between the element and its neighbours.

Outer container
Inner element (margin: 20px 40px)
/* Shorthand — clockwise: top right bottom left */
.box { margin: 10px 15px 20px 12px; }

/* Two values: top/bottom  left/right */
.box { margin: 10px 15px; }

/* One value: all sides */
.box { margin: 10px; }

/* Individual sides */
.box { margin-top: 23px; margin-left: 13px; }

/* Center horizontally (needs a set width) */
.box { margin: 0 auto; width: 600px; }

padding

Space inside the border, between the border and the content.

padding: 30px 60px
/* Same shorthand rules as margin */
.box { padding: 10px 15px 20px 12px; }
.box { padding: 10px 15px; }
.box { padding: 10px; }
.box { padding-top: 23px; padding-left: 13px; }

border

A line drawn around the element's padding area.

/* Shorthand: width style color */
.box { border: 2px solid #0077b6; }

/* Individual sides */
.box { border-top: 4px dashed red; }

/* Individual properties */
.box {
  border-width: 5px;
  border-style: ridge;
  border-color: purple;
}

/* Multiple colors (one per side: top right bottom left) */
.box { border-color: red green #BB0FC3 blue; }
