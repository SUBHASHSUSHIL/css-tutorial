Class & ID Selectors

Class Selector ( . )

A class can be reused on multiple elements, and one element can carry multiple classes (space-separated).

I use class .highlight
I use both .highlight and .fancy-font
/* CSS */
.highlight  { background-color: #ffd166; }
.fancy-font { font-style: italic; }

<!-- HTML -->
<div class="highlight">One class</div>
<div class="highlight fancy-font">Two classes</div>

ID Selector ( # )

An ID must be unique per page — only one element may use a given ID. An element can only carry one ID at a time.

I use id #primary-box
I use id #secondary-box
/* CSS */
#primary-box   { border: 3px dashed #e63946; }
#secondary-box { background-color: #ffc8dd; }

<!-- HTML -->
<div id="primary-box">...</div>
<div id="secondary-box">...</div>

Class vs ID — Quick Reference

Feature          Class ( . )         ID ( # )
───────────────────────────────────────────────
Reusability      Many elements       One element per page
Multi-apply      Multiple per tag    Only one per tag
CSS symbol       .classname          #idname
Specificity      0-1-0               0-1-0-0 (higher)
Best use         Styling groups      Anchor links, JS hooks
