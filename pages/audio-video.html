Audio & Video in HTML

<audio> Tag

Embeds audio with native browser controls. Always provide a fallback message for unsupported browsers.

Basic audio player

<audio controls>
  <source src="audio/sample.mp3" type="audio/mpeg">
  <source src="audio/sample.ogg" type="audio/ogg">
  Your browser does not support the audio element.
</audio>

Useful attributes

controls  — show play/pause/volume UI
autoplay  — start playing automatically (often blocked by browsers)
muted     — start muted (required for autoplay in most browsers)
loop      — repeat when finished
preload   — "none" | "metadata" | "auto"

<video> Tag

Basic video player (local file)

<video width="320" height="200" controls muted poster="poster.jpg">
  <source src="video/example.mp4" type="video/mp4">
  <source src="video/example.webm" type="video/webm">
  Your browser does not support the video element.
</video>

Useful attributes

controls  — show player UI
autoplay  — auto-start (needs muted to work without user gesture)
muted     — start silenced
loop      — repeat
poster    — image shown before playback starts
width / height — dimensions in px (use CSS for responsiveness)

<iframe> — Embed External Content

Use <iframe> to embed YouTube videos, maps, or other web content. Always set title for accessibility.

YouTube embed (copy the embed URL from "Share → Embed")

<iframe
  width="320"
  height="200"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="Video title"
  allowfullscreen>
</iframe>

<object> Tag

An older, more general embedding tag. Prefer <video> for video and <iframe> for web content. 

<object data="video/example.mp4" type="video/mp4" width="320" height="200">
  <p>Your browser cannot play this video.</p>
</object>
