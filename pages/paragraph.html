Paragraph & Inline Text Tags

HTML provides many inline tags to add semantic meaning to text inside paragraphs.

<b>

This word is bold using the presentational <b> tag.

<strong>

This word is strongly emphasised — use this for semantic importance.

<i>

This text is italic using the presentational <i> tag.

<em>

This text is emphasised — screen readers stress this word.

<u>

This text is underlined. Avoid using this for links — it causes confusion.

<del>

This text is deleted / struck through using <del>.

<s>

This text is no longer accurate using <s> (presentational strikethrough).

<mark>

This text is highlighted using <mark>.

<sup> / <sub>

Chemical formula: H2O  |  Math: x2 + y2 = z2

<abbr>

Hover over this abbreviation: CDN

<pre>

The <pre> tag preserves whitespace and line breaks:

Name:    Jane Doe
Email:   jane@example.com
City:    Faridabad

b vs strong / i vs em

<b>  — bold, purely visual (no extra meaning)
<strong> — bold + semantic importance (prefer this)

<i>  — italic, purely visual
<em>  — italic + semantic stress (prefer this)
