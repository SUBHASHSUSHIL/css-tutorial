Display Property

display: block

Each box starts on a new line and stretches to full width.

Block 1
Block 2
Block 3
div { display: block; } /* default for div, p, h1–h6, etc. */

display: inline

Elements sit side-by-side. width and height are ignored; size is determined by content.

Inline 1
Inline 2
Inline 3
span { display: inline; } /* default for span, a, img, etc. */

display: inline-block

Best of both worlds — flows inline and respects width/height.

IB 1
IB 2
IB 3
IB 4
button { display: inline-block; width: 100px; height: 40px; }

.hidden-none { display: none; }

.hidden-vis  { visibility: hidden; }

float & clear

float was the old layout tool before Flexbox/Grid. Still useful for wrapping text around images.

float: left
float: right

This text flows around the floated boxes. Themes and styles help keep your document coordinated. When you click Design and choose a new Theme the pictures and charts change to match. 

.image  { float: left; margin-right: 12px; }
.footer { clear: both; } /* prevents collapsing parent */

cursor

Controls the mouse cursor shape when hovering an element.

div { cursor: pointer; } /* hand icon */
div { cursor: wait; }    /* spinner */
div { cursor: not-allowed; }

→ See the full cursor showcase on the Cursor Types page.
